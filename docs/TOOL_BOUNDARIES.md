# 检查边界

## 所实现的检查

CSV结构/大小/编码；身份与日期；正执行价与静态单位；重复记录；非有限/负/零价格；价格语义；声明事件覆盖、跨事件及生效日拒绝；来源与主表引用缺失；价格、现货和输入已知时序；双边报价与整数深度；唯一完整整对和时戳容差；mid一致性；原始输入和配置哈希绑定。

严重度error表示该问题不适用或输入矛盾；missing_evidence表示不能证明所需条件；warning表示须人工理解的限制。all适用于两种输入问题，historical_iv与pair分别限定作用域。查看机器JSON每条问题的明确scope与repair，不要把另一个问题的待补证当成已解决。

## 状态边界

blocked > needs_evidence > conditional_input_consistent。最后一个只意味着程序所实现检查与用户声明相容。它不证明合法取得、母集覆盖、参考条款真实性、交易可实现性或模型统计有效性。输入引用和事件覆盖必须被独立审阅。没有许可字段通过就称“可以发布”的逻辑。

本版本静态条款不支持跨除息调整或调整单位，拒绝而不重写原值。官方当前规则、事件公告与历史master是不同证据。SSE期权是欧式且通常实物交割；不能把所有历史条款硬编码成当前规则。

- [SSE50ETF规范](https://english.sse.com.cn/markets/derivatives/overview/50etf/)
- [2024调整公告](https://www.sse.com.cn/assortment/options/disclo/update/c/c_20241129_10765181.shtml)
- [2025调整公告](https://star.sse.com.cn/assortment/options/disclo/update/c/c_20251216_10801845.shtml)：调整后单位与真实执行价变化，代码尾部不保证等于真实执行价。
- [结算价规则](https://www.sse.com.cn/assortment/options/rule/c/c_20210128_5312075.shtml)：可能含理论或其他合约信息，不是独立可执行真值。

没有实现完整每日ID母集/覆盖验收、公告前分红预期恢复、曲线bootstrap、动态交割现金流、carry区间拟合、报价异常的自动修复、金融建议、交易或数据下载。定价层另有数值检查，不能补造历史证据。

## 错误处理与隐私

 malformed输入退出2并给友好消息，不产生报告目录；已有输出目录不覆盖。没有上传、CDN、脚本执行、URL加载或用户文件写回。HTML逐字段转义，CSV不经Excel打开。输出按记录号指出问题，默认不带原始价格/合约ID；用户配置、引用和额外列名仍可能私有，不能无审阅共享。输出目录写入中断可能留下部分文件，应另选新目录重跑；报告不具备数字签名或认证功能。

rc4价格核验：mid与有效有序bid/ask均值的比较独立于数量/深度；给定矛盾阻断历史IV和整对。报价价格缺失/非法时mid无法核验，历史IV待补证。深度问题仍仅作用于配对。

现有needs_evidence桶还包含已给但当前配对用途不接纳的输入，如close用于mid配对或非法/零数量；这不是补来源即可转相容的承诺。读issue代码与原因：close须取得不同语义的同步报价，零深度须取得真实有效深度或保留不适用。此次只澄清此口径，未借改标签重算盲测原分。
